# 开发日志 2026-06-01

## Vires —— 将前台心跳扩展到 machina 预填充/解码 + ASR

本次提交：

- `738fc66` feat(vires): broaden Foreground heartbeats to machina + ASR

`accuracy(tests/test.mp3, diarization): 93.5% → 93.6%   (Δ = +0.1 pp)`

### 本次改动

此前只有 `orator_spk_encoder` 会发出 Vires 的 `note_submit` 心跳，因此前台
让路（Foreground-yield）仲裁——以及 WebUI 的 vires 面板——只反映了说话人编码器
的负载。其余每个前台 GPU 消费者虽然都向 Arbiter 注册，却从不上报活动，导致其
`submitted` 计数始终为零，其负载对 `background_should_yield()` 完全不可见。

本次改动为每个拥有计算流（compute stream）的前台消费者补上同样一行、按位完全
等价的心跳：

- machina 预填充（`forward_prefill`）→ `state.vires_compute_id`
- machina 解码（`forward_one_token` / `forward_one_token_sampled`）→
  `state.vires_compute_id`
- auditus ASR 编码器（`ASREngine::transcribe`）→ `vires_id_`

每处都是在已有的 `cudaStreamSynchronize` 之后插入单行
`vires::Arbiter::instance().note_submit(id)`。它不改变任何 kernel、任何数学
运算、任何执行顺序——只是递增对应消费者的 `submitted` 计数，并刷新后台 DiariZen
路径用于判断是否让路的 `last_foreground_submit_us_` 时间戳。`note_submit` 只
持有一把短暂的互斥锁，没有嵌套锁或回调，因此不存在死锁或重排风险。

最终效果：`background_should_yield()` 现在会尊重所有活跃消费者（而不仅是说话人
编码器）的真实前台负载，且 WebUI vires 面板会显示预填充、解码、ASR 的真实
`submitted` 计数，而不再是一片零。

### 实机验证（宪法门禁）

通过 `tools/diarizen_live_score.py` 对 `tests/test.mp3`（3615.1 秒）以 8×
速度完整实机回放，并经由原生流水线 finalize：

- 1653 段，`audio_sec=3615.12`，`wall_sec=359.91`
- 527 / 531 条 GT 话语被判定，覆盖率 0.992
- macro = 0.916，**micro = 0.936**
- 分说话人（仅判定）：唐云峰 0.939 · 徐子景 0.920 · 朱杰 0.835 · 石一 0.971
- **`accuracy(tests/test.mp3, diarization): 93.5% → 93.6%   (Δ = +0.1 pp)`**

心跳在构造上即与 GPU 数学按位等价，因此说话人日志（diarization）准确率在
逐次运行噪声范围内保持不变。同一次运行中实测确认了 `spk_encoder` 心跳在持续
攀升（`submitted` 63 → 240，`background_yielding` 在
`foreground_idle_us=4073` 时翻转为 `True`）。machina 与 ASR 的心跳按构造即正确
——与之完全相同的单行模式、干净编译——只是在非饱和运行下才可观测（8× 时流水线
饱和：16 833 次 `audio_drop` 事件使 ASR 工作线程饿死，而 diarizen 门禁也不会
触发 LLM 解码）。

## Vires V3 — 类淋巴清除（非 LLM 临时显存回收）

V1 已为每个消费者保存 `reclaim_cb` 却从不调用；V2 增加了背压与遥测。V3 闭合
回路：当一次**非 LLM** 的 GPU 计算完成时，Vires 调用该消费者的回收回调，把它
借出的临时暂存显存交还——即计算副产物的「类淋巴清除」（RFC 13）。不触碰任何
LLM 分配；LLM 的废弃显存仍归 Memoria 处置。

### 改了什么（仅调度/生命周期——数学逐位一致）

- `ConsumerStat` 新增单调递增的 `reclaimed` 计数（与 `submitted` 并列），经
  `vires_compute_snapshot` WS 消息暴露，并在 WebUI `vires-panel` 中新增
  **Reclaimed** 列。
- 新增门面方法 `Arbiter::note_pass_complete(id)`。它在锁**内**把消费者的
  `reclaim_cb` 复制出来、递增 `reclaimed`，随后释放锁、在锁**外**调用该回调
  ——保持 V1/V2 的不变量：任何回调都不在 Vires 互斥锁下运行（无嵌套锁/死锁
  风险）。对未知 id 或无回调的消费者为空操作。
- Background 的 `diarizen` 消费者注册了回收回调
  （`segmenter.release_scratch()`），并在每次 `DiarizenPipeline::diarize`
  结束时调用 `note_pass_complete`。`release_scratch()` **只**释放前向的临时
  副产物——WavLM-pruned 编码器的按尺寸索引的暂存空闲表 + 其按需分配的 cuDNN
  卷积工作区，以及 Conformer 头的暂存空闲表。持久状态（权重 arena、fp32 权重
  缓存、cuBLAS/cuDNN 句柄、`loaded_`）全部保留，模型保持就绪，下一次计算时
  惰性重建其暂存池。这些缓冲区在被读取前总会被完整覆写，因此清除与重新分配
  逐位等价。ResNet34 嵌入器没有暂存池，因而无可回收。

### 真机验证（宪法门禁）

8× WS 回放 `tests/test.mp3`（3615.1 s）+ 原生 `diarizen_finalize`，对照
`tests/fixtures/test_ground_truth.json` 评分：

- 1653 段，`wall_sec=358.30`，527 / 531 判定，覆盖率 0.992
- macro = 0.916，**micro = 0.936**
- 分说话人（仅判定）：唐云峰 0.939 · 徐子景 0.920 · 朱杰 0.835 · 石一 0.971
- **`accuracy(tests/test.mp3, diarization): 93.6% → 93.6%   (Δ = 0.0 pp)`**

按构造，清除逐位一致（暂存是被回收的内容，读取前必被覆写），故准确率不变。
真机 WS 快照确认在唯一一次 finalize 计算里回路恰好触发一次：
`diarizen submitted=1 reclaimed=1`。HTTP 200、WS 101，面板渲染出新的
Reclaimed 列。

## DiariZen PERIODIC 模式 finalize：并发 `diarize()` 触发 cuDNN 崩溃

### 症状

开启 `DEUSRIDET_DIARIZEN_PERIODIC=1`（定时窗口 pass）后，会话末尾的
`diarizen_finalize` 返回空分段（`diarize: segmentation empty`）——宪法准确率
门禁无内容可评。`PERIODIC=0` 不受影响，仍产出标准 93.6%。

### 根因

`DiarizenPipeline::diarize()` **不可重入**：它在单一 CUDA 流上驱动一组共享的
WavLM / Conformer GPU 暂存缓冲区。在 PERIODIC 模式下，周期工作线程与分离的
`finalize()` WS 处理线程可能在同一瞬间进入 `diarize()`。两次 pass 互相破坏
对方的暂存——`/tmp` 日志显示在完全相同的时间戳上，**两个** pass 都在
`run_cnn_` 中报 `CUDNN_STATUS_EXECUTION_FAILED_CUDART`（`WavLM batched tail
failed`：一个 180 s 周期片段在 chunk 72，整会话 finalize 在 chunk 440）。
finalize pass 因此以空结果中止。

### 修复

将每一次 `diarize()` pass 串行化：

1. `finalize()` 现在**先**调用 `stop()`，join 工作线程，使任何定时窗口 pass
   都无法与整会话 final pass 重叠（同时省去一次无谓的尾随周期 pass）。
2. `run_one_pass_()` 在整个函数体上持有新的 `pass_mutex_`，也防止第二次并发
   `finalize()`。`pass_mutex_` 与 `mu_` 独立（工作线程在调用
   `run_one_pass_` 前已释放 `mu_`），故不会死锁。

### 真机验证（宪法门禁）

PERIODIC=1（WINDOW=180 s、PERIOD=90 s）下 2× WS 回放 `tests/test.mp3`
（3615.1 s）+ 原生 `diarizen_finalize`：

- 16 次周期 pass 全部成功，**零 CUDNN 错误**
- finalize `ok:true`，1653 段，`wall_sec=356.73`，527 / 531 判定，覆盖率 0.992
- macro = 0.916，**micro = 0.936**
- 分说话人（全部）：唐云峰 0.939 · 徐子景 0.920 · 朱杰 0.835 · 石一 0.971
- **`accuracy(tests/test.mp3, diarization): 0% (PERIODIC=1 finalize crashed → empty) → 93.6%   (Δ = +93.6 pp)`**
