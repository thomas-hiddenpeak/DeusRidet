# 2026-05-26 — 第十四阶段：可靠度加权亲和度（full_60m 回退）

## 摘要

实现昨日 devlog 中预告的第十三阶段后续方案（"在 reclusterer 内部按
每段可靠度 `w_i = min(1, dur_i / 1.5)` 给亲和矩阵加权，而不是事后覆盖
标签"）。代码落在该落的位置——`build_similarity()` 内部，由配置开关
门控。s1800 最高提升 **+1.03 pp**，但 **full_60m 最高回退 −3.56 pp**。

这是连续第三个"赢 s1800 输 full_60m"的窗内杠杆（第五阶段 K-mode、
第八阶段 purity split、第十四阶段亲和度加权）。第六阶段默认值
`window_sec=180`（s1800=0.7935 / full_60m=0.7032）的天花板依然成立。

## 算法

在 `src/orator/spectral_cluster_affinity.cpp::build_similarity()` 中，
位于（已实际禁用的）时序混合块之后：

```cpp
if (affinity_weighted && weights.size() == N && affinity_dur_ref > 0) {
    std::vector<float> w(N);
    for (int i = 0; i < N; ++i) {
        w[i] = std::clamp(weights[i] / affinity_dur_ref, 0.0f, 1.0f);
    }
    for (int i = 0; i < N; ++i) {
        for (int j = i + 1; j < N; ++j) {
            float s = std::sqrt(w[i] * w[j]);
            sim[i * N + j] *= s;
            sim[j * N + i] = sim[i * N + j];
        }
    }
}
```

对角线保持不变（自亲和度仍为 1.0——不是把片段静音，而是让它对其他
片段的吸引力变小）。权重由 `OratorReclusterer::run_pass()` 提供
（片段时长，与第九阶段同源）。

## 结论

- 默认保持 **OFF**。代码作为 opt-in 杠杆保留（仅 CLI 可用）。
- Commit 信息：`experiment(orator): reliability-weighted affinity
  in build_similarity (Phase 14, negative on full_60m)`。
- 第六阶段天花板（s1800=0.7935 / full_60m=0.7032）依然是规范基线；
  第七/十/十一阶段的运行时路径保持不变。

## 模式识别（连续三次窗内杠杆失败）

| 阶段 | 杠杆 | s1800 Δ | full_60m Δ |
|----:|------|--------:|-----------:|
| 5  | 特征值比 K 选择 | -20.79 | n/a (放弃) |
| 8  | purity 事后切分 | +0.25 | **−2.94** |
| 9  | 长度加权 K-means | -0.29 | -0.86 |
| 14 | 可靠度加权亲和度 | **+1.03** | **−1.63** |

每一个改动 K-means/亲和度的窗内质量杠杆，都在 full_60m 上回退。
只有第六阶段（`window_sec=180`）和第十阶段
（`max_global_speakers` 设为 K_gt+1，噪声中性）幸存。

**工作假设**：full_60m 的 macro_f1 主要由跨窗 Hungarian 链接稳定性
决定，而不是窗内聚类纯度。下一次进攻方向应该指向 linker（或
`centroid_ema` 调度、或全局图松弛步骤），而不是窗内 spectral 流程。
