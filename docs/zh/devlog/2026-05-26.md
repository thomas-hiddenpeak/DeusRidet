# 2026-05-26 — 第十四阶段：可靠度加权亲和度（full_60m 回退）

## 摘要

实现昨日 devlog 中预告的第十三阶段后续方案（"在 reclusterer 内部按
每段可靠度 `w_i = min(1, dur_i / 1.5)` 给亲和矩阵加权，而不是事后覆盖
标签"）。代码落在该落的位置——`build_similarity()` 内部，由配置开关
门控。s1800 最高提升 **+1.03 pp**，但 **full_60m 最高回退 −3.56 pp**。

这是连续第三个"赢 s1800 输 full_60m"的窗内杠杆（第五阶段 K-mode、
第八阶段 purity split、第十四阶段亲和度加权）。第六阶段默认值
`window_sec=180`（s1800=0.7935 / full_60m=0.7032）的天花板依然成立。

## 算法

在 `src/orator/spectral_cluster_affinity.cpp::build_similarity()` 中，
位于（已实际禁用的）时序混合块之后：

```cpp
if (affinity_weighted && weights.size() == N && affinity_dur_ref > 0) {
    std::vector<float> w(N);
    for (int i = 0; i < N; ++i) {
        w[i] = std::clamp(weights[i] / affinity_dur_ref, 0.0f, 1.0f);
    }
    for (int i = 0; i < N; ++i) {
        for (int j = i + 1; j < N; ++j) {
            float s = std::sqrt(w[i] * w[j]);
            sim[i * N + j] *= s;
            sim[j * N + i] = sim[i * N + j];
        }
    }
}
```

对角线保持不变（自亲和度仍为 1.0——不是把片段静音，而是让它对其他
片段的吸引力变小）。权重由 `OratorReclusterer::run_pass()` 提供
（片段时长，与第九阶段同源）。

## Phase 15 — `spectral_cluster()` 全 GPU 化

### 指令

> "我们的计划是要完全通过 GPU 来计算的哟，任何主要计算放在 CPU 上都不是我们
> 的预期设计，CPU 应该只负责任务调度和完全无法在 GPU 上执行的操作。"

把原本 CPU 上的 Stage 0–9 全部迁到一个 CUDA translation unit：用 cuBLAS
SGEMM + 自写 kernel 完成所有 N×dim 与 N×N 张量运算。CPU 只剩下任务
调度、host 侧 K-means++ farthest-point 初始化、特征值排序与 K 选择、
时序平滑标签重映射，以及末端的小规模 "merge similar clusters"。

### 实现

- **新增**: `src/orator/spectral_cluster_gpu.cu`（约 900 行）
  - Lazy `GpuCtx` 单例持有一个 cuBLAS handle + 一条 stream + 约 25 个
    "只增不减" 的 device buffer（`ensure_capacity`），每 tick 零
    `cudaMalloc`。
  - `gemm_row()`：row-major SGEMM 包装器。**首版踩坑**：标准
    "交换 A/B、交换 M/N" 的 col-major 转换中 op flag 是 **恒等映射**
    而不是取反；首版取反后触发 `CUBLAS_STATUS_INVALID_VALUE`（错误 7）。
  - Kernel 列表：`k_col_mean`、`k_subtract_mean`、`k_scale_inv_sqrt`、
    `k_deflate`、`k_l2_normalise_rows`、`k_set_diagonal`、
    `k_temporal_mix`、`k_apply_reliability`（Phase 14 可靠性权重）、
    `k_clamp_weights`、`k_prune_topp`（重复 argmax + 共享内存 mask）、
    `k_symmetrize`、`k_row_sum`、`k_orphan_repair`、`k_laplacian`、
    `k_extract_features`、`k_kmeans_finish_dist`、`k_kmeans_assign`、
    `k_kmeans_update`、`k_sum_by_label`。
  - PCA 与 Laplacian 谱嵌入都走 deflated power iteration
    （`topk_power_iter`）完全在设备上完成。
  - K-means++ farthest-point 初始化在 host 上以确定性种子
    `restart*137 % N` 完成，centroid 推回 device，随后 30 轮
    assign/update kernel；Phase 9 length-weighted update 已接入。
- **删除**: `spectral_cluster.cpp`、`spectral_cluster_affinity.cpp`、
  `spectral_cluster_embed.cpp`、`spectral_cluster_postprocess.cpp`、
  `spectral_cluster_stages.h` 五个 CPU stage 文件，共约 1500 行。
- **未动**: `spectral_cluster.h`（公开 API）、`orator_reclusterer.*`、
  `tools/orator_reclusterer_eval.cpp`。下游零改动。

### 数值验证

| 切片 | CPU 基线 | GPU 移植 | Δ |
|------|---------|---------|---|
| s1800 (`--end-sec 1800`) | 0.7935 | **0.7935** | 0 |
| full_60m (`--end-sec 3600`) | 0.7032 | **0.7032** | 0 |

成分另说，但算法等价性已建立。
